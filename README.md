# cv-generator

一个纯前端的简历生成器。编辑 `resume.template.toml` 或你自己的 `TOML` 文件，然后在浏览器中加载并导出为 PDF。

## 使用方式

1. 可以直接打开 `index.html`，也可以在仓库根目录启动一个本地静态服务。
2. 点击“加载配置文件”，选择 `resume.template.toml` 或你自己的配置文件。
3. 检查顶部状态提示，确认内容是否接近一页或已经超页。
4. 点击“生成 PDF”，进入浏览器打印预览并另存为 PDF。

## 配置说明

配置文件格式为 `TOML`，主要包含以下字段：

- `[basic]`：姓名、岗位、手机号、邮箱、主页、城市、补充信息
- `[[skills]]`：技术栈分类与内容
- `[[projects]]`：项目经历，最多显示 3 条
- `[[work_experiences]]`：工作经历，最多显示 3 条
- `[education]`：教育背景
- `[summary]`：个人评价

可以直接参考 `resume.template.toml`。

## 说明

- 页面默认以 A4 纸比例渲染。
- 当内容偏多时，技术栈区域会自动切换为两列以节省纵向空间。
- PDF 导出依赖浏览器原生打印能力，不引入额外后端或 PDF 服务。
- 如果是直接用 `file://` 打开 `index.html`，浏览器通常不会自动读取同目录的 `resume.template.toml`；这种情况下请手动点击“加载配置文件”，或改用本地静态服务打开页面。
